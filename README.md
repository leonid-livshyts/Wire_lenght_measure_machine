# Intro

It's machine which will count how much wire have gone though it and wind a new rope hank with an acurate length. It consists of roll which is connected to the encoder by gears and counts how much string have gone through it and a motor which pulls the string through the machine. It's controlled by RP2350b. The display and additional encoder will help to set the length of needed hank and to calibrate the mechanism. The mechanism is powered with 12V, 2A power supply. It has a small motor driver to controll speed and smothly controll the stop of the machine.
